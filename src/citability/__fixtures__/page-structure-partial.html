Setup steps

Install the CLI and log in with your account. Configure the target URL and run the first audit.

After the audit completes you can schedule recurring checks, compare scores over time and export the report for your team. The scheduling tab also lets you pause a subscription, change the billing cycle, invite additional members, review the access log and download every generated PDF for compliance purposes. You will find the full reference in the appendix of this guide. That appendix covers the CLI flags, the environment variables, the webhook payloads and the rate limits for every plan tier. Each section also includes a worked example with the expected output.
