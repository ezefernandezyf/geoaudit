# Proposal: Sprint 11 — Rebrand to Relevy + polish

## Intent

The product is feature-complete and owns `relevy.app`, but still ships under the placeholder brand "GeoAudit" everywhere the user can see it (copy, metadata, JSON-LD, PDF, llms.txt, emails) and links to the temporary `geoaudit-tau.vercel.app` domain. Three defects also ship today: anonymous audits are unthrottled (only the 5/60s burst limiter applies), the citability report can show the same passage as both "best" and "worst" on short pages, and the legal copy still describes a paid/free-model that no longer exists. This change completes the rebrand and closes those gaps.

## Scope

### In Scope
- **Rebrand GeoAudit → Relevy** across ~30 production files + 9 test files + `public/llms.txt` (also fixes the stale "3 auditorías mensuales" claim → 10/30d). Contracts are untouched (no brand mentions). Historical briefs/spec files are NOT touched.
- **Logo/wordmark**: redesign `src/ui/logo.tsx` + `src/app/icon.svg` to a Relevy mark (mark generated by the user via Gemini using `docs/RELEVY-BRAND-BRIEF.md`; SVG integrated in apply).
- **Support email** `ezefernandezyf@gmail.com` extracted to one shared constant (copy.ts:265, copy.ts:337, footer.tsx:52).
- **Anonymous limit**: 3 audits / 30-day fixed window per IP via a second limiter `getAnonymousAuditLimiter()` (`anon:{ip}`, `rateLimitEntry` table, no schema change). Enforced only in `audit-runner.tsx` as the authoritative gate; no pre-check in actions.ts.
- **Citability fix**: derive `bottom3` from blocks NOT in `top3` (`src/citability/index.ts:101-102`); when <3 non-overlapping blocks remain, show fewer.
- **Legal copy**: rewrite `LEGAL_COPY.terms[2]` ("Planes y facturación") and drop "procesar pagos" (`privacy[1]`) for the free model.
- **Sprint-10 suggestions**: unify `free`/`Plan Free` pill; add `NEXTAUTH_URL` + `NEXT_PUBLIC_APP_URL` to `.env.example`; clear stale comments (layout.tsx:42, score-hero-evidence.ts:24).
- **Operational docs**: README, AGENTS, llms.txt (repo-rename manual step documented; update GitHub `sameAs`/link to `relevy`).

### Out of Scope
- NO Brand Authority (Sprint 12). NO monetization/payments. NO Cloudflare. NO product visual redesign (mark only). NO historical briefs (`geo-saas-brief.md`, `STYLE-BRIEF.md`, `DESIGN-BRIEF-export.md`, calibration/performance docs). NO contract changes. NO `openspec/specs/` historical rewrites.

## Capabilities

### New Capabilities
- None.

### Modified Capabilities
- `audit-limits`: anonymous audits now count against an IP-based 3/30d limit (TLM-6 delta).
- `rate-limiting`: add `getAnonymousAuditLimiter()` singleton (3/30d, `anon:{ip}`) alongside the burst limiter.
- `citability-engine`: `top3`/`bottom3` must be disjoint (RCI-10 delta).
- `app-shell`: logo wordmark + navbar/footer brand → Relevy (spec scenario text).

## Approach

String-level rename with a single shared brand constant to stop future drift. Anonymous limiter reuses the existing `createRateLimiter` + `PrismaRateLimitStore` (30-day window, `maxRequests: 3`), gated in `audit-runner.tsx` where the signed-in tier gate already lives. Citability fix reorders the existing `scored` array so `bottom3` is computed over the complement of `top3`. Legal copy is a pure text edit (no test assertions).
